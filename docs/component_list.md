# Component List

| Component | Purpose |
|---|---|
| Arduino Uno | Main controller |
| GUVA-S12SD UV sensor module | Analog UV sensing |
| MPU6050 | Motion/orientation context |
| SSD1306 128x64 I2C OLED | Readout |
| Buzzer | Audible alert |
| Breadboard and jumper wires | Prototyping |
| USB power / suitable regulated supply | Power |

Check the exact breakout-board voltage requirements before wiring. Do not
assume every module accepts 5 V logic or supply.
