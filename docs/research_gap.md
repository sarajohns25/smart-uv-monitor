# Research Gap

Many low-cost UV monitors report instantaneous UV intensity or use a fixed
threshold alert. This project explores combining continuous UV sensing,
time-integrated exposure estimation, a user-selectable sensitivity profile,
measurement-uncertainty margin, and motion context in a compact wearable
prototype.

The intended contribution is an integrated and testable workflow rather than
a claim that these features are individually unprecedented. A literature
review is required before making a novelty claim. Personalization thresholds
must be justified from reliable standards and validated before real-world use.
